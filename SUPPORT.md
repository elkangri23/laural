# Ayuda y soporte

- Para errores reproducibles, usa la plantilla de [informe de error](https://github.com/elkangri23/laural/issues/new?template=bug_report.yml).
- Para proponer una función, usa la [propuesta de mejora](https://github.com/elkangri23/laural/issues/new?template=feature_request.yml).
- Para vulnerabilidades, sigue [SECURITY.md](SECURITY.md); no abras un issue público con detalles sin parchear.
- Para compilar desde código, sigue [Configuración de desarrollo](docs/development/setup.md).

Antes de compartir logs, elimina API keys, salida de terminal, rutas privadas y datos de proyecto. La compatibilidad de un endpoint depende de que implemente los endpoints OpenAI-compatible que usa Laural.
