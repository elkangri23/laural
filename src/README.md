# Laural · src

App.tsx coordina las sesiones y el asistente. `streamingText.ts` mantiene las respuestas del chat por fragmentos y compone una instantánea solo cuando la interfaz la necesita. `terminalOutput.ts` valida y decodifica salida PTY Base64, agrupa sus escrituras a xterm en ventanas de 16 ms (con flush al llegar a 256 KiB o cerrar), agrupa el contexto y deduplica los IPC de redimensionado. `TerminalPane` limita el parpadeo del cursor a la terminal visible y activa. Los eventos Rust/TypeScript se definen en `src-tauri/src/terminal_output.rs` y `TerminalPane`. `themes.ts` define las paletas. Los componentes de terminal y configuración están en `components`. La persistencia de perfiles y credenciales se gestiona en el backend.
