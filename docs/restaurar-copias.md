# Restaurar copias de archivos del agente

Después de aplicar un cambio de archivo, abre **Copias de seguridad**, elige una versión y pulsa **Restaurar copia**. Laural pide confirmación. Antes de restaurar conserva el archivo actual como una nueva versión. La lista enseña hasta veinte versiones recientes.

Las copias permanecen en `.laural-backups` dentro del proyecto. No se incluyen en el contexto automático. La limpieza manual de copias antiguas sigue pendiente.
