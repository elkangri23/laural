# Configurar Laural

Abre **Configuración** en la barra lateral. Los ajustes se organizan en cinco categorías para agrupar las opciones relacionadas; al volver de un diálogo se conserva la categoría de origen. El panel adapta la navegación a ventanas estrechas y permite recorrer las categorías con el teclado. La interfaz ofrece español e inglés, con localización general aún en curso; los encabezados de categorías y estados de carga también se traducen. Los ajustes pertenecen al equipo actual.

La versión actual incluye **Importar y exportar configuración** sin cuenta y **Cuenta y sincronización**. Con una sesión válida, puedes comparar snapshots sin mostrar diferencias, subir la configuración local inicial o elegir cuál conservar. Tras acordar la línea base, Laural sincroniza automáticamente preferencias y perfiles, reintenta cambios offline y comprueba cada tres horas. Si la nube avanzó por otro equipo, pide una elección antes de escribir. Aplicar la nube crea primero una copia local `.laural` sin claves. En **Historial de preferencias en la nube** puedes consultar páginas de versiones, restaurar una como nueva revisión (con copia local previa) o eliminarla. El historial no caduca automáticamente y se borra al eliminar la cuenta; las claves API no se guardan en él. En Cuenta puedes borrar definitivamente la cuenta y los datos de nube: requiere un login de menos de diez minutos y escribir `ELIMINAR`. Se borra el token y la línea base local de sync, pero perfiles, preferencias y claves API locales permanecen. Si la conexión se corta durante la solicitud, comprueba con el administrador antes de repetir. El VPS responde a sus comprobaciones públicas, pero aún falta validar desde Laural los flujos integrados y el contrato de snapshot v2. Consulta el [plan y su estado](plans/sincronizacion-preferencias.md) y el [diseño](designs/sincronizacion-preferencias-y-portabilidad.md).

| Categoría | Opciones |
| --- | --- |
| **Personalización** | Apariencia: selecciona una de las doce paletas y el modo claro u oscuro. El cambio se aplica de inmediato. Idioma: español/inglés con detección inicial y guardado local. La traducción está en progreso: cubre shell, Ajustes, proveedor, paneles principales, permisos y advertencias del agente, Cuenta/sincronización, Importar/exportar, Actualizaciones, controles de terminal y varios estados dinámicos de la app. El idioma viaja en exportaciones v2 y en snapshots v2; falta validar el contrato v2 en el VPS desde la app antes de publicar la sincronización del cliente. |
| **IA** | Proveedores y modelos: selecciona un perfil o crea uno. Elige proveedor, nombre, URL base, modelo y clave si el servidor la exige. Puedes autorizar por perfil que la URL se incluya en una futura sincronización; está desmarcado por defecto. Consulta los modelos y guarda el perfil. El chat usa el proveedor activo. |
| **Agente y terminal** | Permisos del agente: confirmar cada comando, ejecutar reglas exactas o modo automático limitado a consultas de Git. Los cambios de archivos requieren aprobación. Estas opciones y sus advertencias de seguridad están traducidas al español e inglés. Retención de copias conserva todas las versiones por defecto o entre 5 y 100 copias recientes por archivo. Actividad del agente permite consultar/borrar el registro acotado. También puedes borrar el historial local del chat y activar, de forma optativa, las sugerencias inline nativas de PSReadLine para nuevas sesiones PowerShell. La predicción usa el historial local, puede mostrar comandos sensibles y permanece desactivada por defecto; Laural no la envía a la IA, nube o telemetría. La interfaz de terminal traduce sus avisos, pero conserva comandos y salidas del shell sin modificaciones. |
| **Datos y cuenta** | Importar/exportar un archivo `.laural` v2 (lector v1 incluido), que porta también el idioma. Gestionar Cuenta y sincronización. Las claves se excluyen por defecto; para incluirlas se solicita una contraseña (mínimo 12 caracteres) y se cifran con Argon2id + AES-256-GCM. La importación permite vista previa y fusión o reemplazo, y crea una copia local previa. |
| **Aplicación** | Actualizaciones: consulta la versión instalada, busca ahora, elige instalación manual o automática y descarga una versión para instalarla y reiniciar Laural. La app busca al iniciar y cada seis horas. |

La paleta de comandos se abre con `Ctrl+K` desde el espacio de trabajo. Permite buscar acciones, sesiones y hasta 100 comandos recientes de la sesión; el historial solo vive en memoria y elegir un comando lo copia para revisarlo antes de pegarlo.

Los archivos exportados sin claves contienen nombres, modelos y URLs de los proveedores; considera esas URLs información privada. Una exportación con claves está cifrada, pero quien conozca la contraseña podrá descifrarlas. La copia previa a una importación que cambia claves también se cifra con la contraseña del archivo importado. Sin cambios de claves, la copia local no contiene claves. Chats, terminales, proyectos, reglas del agente e historial no se exportan. La copia local está en el mismo equipo y no sustituye una copia externa.

En el primer inicio puedes escoger el modo de actualización. El modo automático puede cerrar terminales y sus procesos al instalar; guarda antes el trabajo activo. El paquete se valida con la firma criptográfica configurada en la aplicación.

Al probar la conexión, Laural reintenta una vez la consulta de modelos si falla la conexión o el servidor devuelve HTTP 502–504 sin indicar un plazo de espera. El chat requiere un nuevo envío manual si se interrumpe.

Para conectar un servidor local, usa la URL base que muestra el servidor, incluido el prefijo de su API compatible con OpenAI. Si no aparecen modelos, comprueba que el servidor esté iniciado, la dirección y el puerto sean correctos y el perfil tenga la clave correspondiente. Usa HTTPS para un proveedor remoto.

La elección del shell, las divisiones y los archivos adjuntos se hacen en la sesión de trabajo. Usa **Revisar contexto** antes de enviar contenido a un proveedor. Consulta la [política de datos](security/privacy.md).

La opción **Sugerencias locales de PowerShell** se encuentra en **Agente y terminal**. Actívala para que PSReadLine muestre sugerencias del historial local en las terminales PowerShell nuevas; pulsa flecha derecha para aceptarlas y usa Tab para completar. El historial puede contener datos sensibles; la función está apagada inicialmente, no autoejecuta sugerencias y Laural no exporta ni envía el historial a la IA, sync o telemetría. Si PSReadLine no es compatible, el prompt habitual sigue funcionando.

Cada perfil guardado conserva su URL base. Para cambiar de servidor, crea otro perfil e introduce la clave correspondiente.
Las reglas no permiten operadores ni expansión de variables del shell. Escribe cada orden simple como una entrada independiente; las composiciones requieren aprobación manual.
