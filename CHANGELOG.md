# Registro de cambios

## Próxima versión
- El agente da ejemplos completos de búsqueda de imágenes para PowerShell, CMD, WSL y Git Bash. PowerShell filtra extensiones explícitamente; Bash usa `find` con patrones agrupados; CMD conserva sus patrones compatibles. La prueba también comprueba que, ante un shell desconocido, el agente no invente sintaxis.
- El control de riesgo del agente exige revisión antes de crear, borrar (incluido `--delete-merged`), renombrar, copiar o cambiar el seguimiento de ramas Git, incluso con opciones cortas combinadas. Las consultas conocidas se permiten; opciones ambiguas o desconocidas requieren revisión.
- El backend valida antes de llamar al proveedor los límites de tareas, contexto de terminal, diff y archivos seleccionados, además del shell admitido; regresiones cubren los límites inclusivos y excesos.
- Guardar un proveedor valida y normaliza ID, nombre, modelo, tipo, URL y clave antes de acceder al almacén de credenciales; se cubren máximos permitidos y valores rechazados.
- La validación de enlaces de gestión de passkeys rechaza explícitamente URLs con usuario o contraseña embebidos, además de host, ruta, query o ticket no permitidos.
- El bucle del callback OAuth local queda aislado de Tauri para probarlo con sockets locales: acepta el `state` correcto, rechaza cinco intentos inválidos y termina si vence el tiempo de espera. Suite Rust: 236 pasadas, 2 manuales ignoradas; `account.rs` alcanza 60,52 % de líneas y 62,75 % de ramas en CI.
- La lectura de la sesión valida el formato del token antes de usarlo y diferencia sesión ausente, dato inválido y fallo del almacén sin filtrar detalles. Suite Rust: 237 pasadas, 2 manuales ignoradas; `account.rs` llega a 61,83 % de líneas y 64,71 % de ramas en CI.
- La consulta y revocación de sesiones autenticadas validan métodos, cabeceras Bearer, códigos HTTP, JSON y errores de transporte con un servidor local. Suite Rust: 239 pasadas, 2 manuales ignoradas; `account.rs` alcanza 70,04 % de líneas y 68,63 % de ramas en CI.
- Las llamadas de MFA/TOTP comparten helpers acotados para enviar solicitudes autenticadas y validar JSON o respuestas 204. Regresiones locales comprueban confirmación TOTP, carga JSON, enrolamiento sin cuerpo, estados no válidos y errores de transporte. Suite Rust: 241 pasadas, 2 manuales ignoradas; `account.rs` alcanza 73,46 % de líneas y 71,70 % de ramas en CI.
- La gestión de passkeys obtiene y valida el enlace antes de abrir el navegador; una respuesta 403 solicita volver a iniciar sesión y se rechazan destinos externos. Suite Rust: 242 pasadas, 2 manuales ignoradas; `account.rs` alcanza 75,34 % de líneas y 76,42 % de ramas en CI.
- El borrado de cuenta separa la petición remota del comando Tauri y comprueba confirmación `ELIMINAR`, autorización, sesión reciente, respuesta 204 y errores de transporte. Suite Rust: 243 pasadas, 2 manuales ignoradas; `account.rs` alcanza 77,22 % de líneas y 80,19 % de ramas en CI.
- La limpieza local al borrar una cuenta informa por separado si se retiró la credencial de sesión y el estado de sincronización; una credencial inexistente cuenta como borrada y los errores no se ocultan. Suite Rust: 244 pasadas, 2 manuales ignoradas.
- La sincronización ya no dice que local y nube difieren cuando son el mismo ajuste: un snapshot v1 en la nube (sin idioma) y el snapshot v2 local se comparan por su contenido, no por la versión del esquema, así que descargar la nube deja de pedirlo otra vez inmediatamente.
- La comparación de snapshots ignora el idioma cuando una versión v1 no lo contiene, pero detecta diferencias si ambos son v2. `AccountSettings.tsx` conserva cobertura Crítica 100/100 en líneas y ramas; una regresión fija un fixture que usaba `ocean` como supuesto tema distinto aunque era el tema original.
- Las regresiones del clasificador Git cubren también un guion aislado, una opción corta desconocida y un valor de consulta ausente antes de otra opción; las formas ambiguas siguen exigiendo revisión.
